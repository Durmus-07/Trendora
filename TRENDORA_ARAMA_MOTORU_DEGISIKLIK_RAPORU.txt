RENDER ORTAM DEĞİŞKENLERİ
Ana sağlayıcı:
GEMINI_SEARCH_ENABLED=true
GEMINI_API_KEY=<Google AI Studio anahtarı>
GEMINI_MODEL=gemini-2.5-flash
GEMINI_DAILY_LIMIT=20

Birinci yedek:
BRAVE_SEARCH_ENABLED=true
BRAVE_SEARCH_API_KEY=<Brave Search API anahtarı>

İkinci yedek:
TAVILY_SEARCH_ENABLED=true
TAVILY_API_KEY=<Tavily API anahtarı>
